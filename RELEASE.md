## Changelog

### v2.1.0
* Added configurable Mel filter bank frequency range (mel_low_freq, mel_high_freq) to LP init configuration
* Updated Xiaodu Xiaodu wake word model with improved neural network weights
* Updated pre-processing parameters for all wake word models (Alexa, Hey Google, OK Infineon, Xiaodu Xiaodu)

### v2.0.0
* Added support for Mandarin (Xiaodu Xiaodu) wake word model
* Added AMIC and DMIC parameter configurations for all wake word models
* Improved audio processing parameter handling
* Added digital gain control support for audio signal processing

### v1.1.0
* Added configurable Low noise detection event

### v1.0.1
* Added support for NNLITE2

### v1.0.0
* Initial release
