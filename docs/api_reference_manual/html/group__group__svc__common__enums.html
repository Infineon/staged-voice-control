◆ cy_svc_stage_config_t

enum cy_svc_stage_config_t

Staged voice control stage configuration.

Enumerator
CY_SVC_ENABLE_HPF 

Enable High Pass Filter in SVC LP.

CY_SVC_ENABLE_SOD 

Enable SOD transitions in SVC LP.

CY_SVC_ENABLE_LPWWD 

Enable Low Power Wake-up Word (LPWWD) detection in low power domain.

CY_SVC_ENABLE_HPWWD_STATE_TRANSITIONS 

Enable Staged Voice Control (SVC) to wait for High Performance Wake-up Word Detection (HPWWD).

If this option is enabled, then HPWWD detection state will be used by the SVC for its internal stage transitions and actions, otherwise SVC will not consider/wait for HPWWD state. Application needs to set the HPWWD state through the API cy_svc_hp_set_state to SVC.

Note
Enabling this option, will not enable HPWWD detection in high performance domain. The application running on high performance domain needs to take care of the enabling HPWWD module.
CY_SVC_ENABLE_ASR_STATE_TRANSITIONS 

Enable Staged Voice Control (SVC) to wait for Automatic Speech Recognition (ASR) detection.

If this option is enabled, then ASR detection state will be used by the SVC for its internal stage transitions and actions, otherwise SVC will not consider/wait for ASR state response. Application needs to set the ASR state through the API cy_svc_hp_set_state to SVC.

Note
Enabling this option, will not enable ASR in high performance domain. The application running on high performance needs to take care of enabling ASR module.
